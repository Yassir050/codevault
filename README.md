CodeVault 🔐

A modern, mobile-first code snippet manager built with HTML, CSS, and JavaScript.

CodeVault allows developers to save, organize, search, filter, favorite, copy, and delete useful code snippets directly from the browser.

✨ Features

* 📦 Add and save code snippets
* 🔎 Search snippets
* 🏷️ Filter by programming language
* ↕️ Sort by newest, oldest, or name
* ⭐ Favorite snippets
* 📋 Copy code to clipboard
* 🗑️ Delete snippets
* 🌙 Dark mode
* 📱 Mobile-first responsive design
* 💾 Local data persistence with localStorage
* ⚡ No backend required for the current version

🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* LocalStorage API
* Clipboard API
* Google Fonts
    * Inter
    * JetBrains Mono

🚀 How to Run

No installation or backend server is required.

Simply open:

index.html

in a modern web browser.

💾 Data Storage

The current version uses the browser’s localStorage to save snippets.

This means your snippets are stored locally on the device/browser you use.

Clearing the browser’s site data may remove the saved snippets.

📱 Mobile Support

CodeVault is designed with a mobile-first approach and adapts to:

* 📱 Smartphones
* 📲 Tablets
* 💻 Desktop screens
